Governança do catálogo

O aplicativo consulta Portal NFS-e/Receita e Portal NF-e. Ao abrir o simulador, as fontes oficiais são verificadas automaticamente. Uma nova versão só é aplicada quando houver mudança válida; a versão anterior permanece em backup para rollback. Se não houver mudança, nada é alterado. A verificação manual permanece disponível.
